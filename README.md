# هارون بلاست — نموذج تجريبي (تصميم أمازون)

صفحة تجريبية-static لعرض شكل التطبيق بأسلوب متاجر أمازون.
**ليست التطبيق الرسمي** — الطلب لا يُرسل، والبيانات للعرض فقط.

- البيانات تُقرأ مباشرة من Supabase (منتجات + تصنيفات)
- التصميم مستوحى من تطبيق أمازون: ترويسة داكنة، بحث، شرائح تصنيفات،
  بانر عروض، صف "الأكثر طلبًا"، شبكة منتجات، زر أصفر "إضافة إلى السلة"، شريط تنقل سفلي
